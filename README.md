# 나무덤프

나무위키 덤프 파일을 인터넷 없이 읽는 프로그램입니다. 표 색상, 글자 크기, 틀, 수식, 각주, 접기 같은 문서 서식을 되도록 나무위키에서 보던 모습 그대로 보여 줍니다. macOS, Windows, Linux에서 씁니다.

> 나무덤프는 나무위키 운영사와 관계없는 비공식 프로그램입니다.

<p align="center"><img src="docs/screenshot.png" alt="나무덤프 처음 화면: 검색창, 이어서 읽기, 즐겨찾기, 둘러볼 만한 문서" width="800"></p>

## 할 수 있는 것

- **제목 검색**: 입력하는 대로 제목을 제안합니다. 결과 화면에서는 검색어로 시작하는 제목과 검색어가 들어간 제목을 모두 보여 줍니다.
- **위키처럼 읽기**: 문서 안 링크, 뒤로와 앞으로, 목차(본문 안과 오른쪽), 문단 접기, 각주 말풍선, 접기 상자, 틀의 탭 전환
- **서식 살리기**: 표 색상, 글자 색과 크기, 수식(KaTeX), 들여쓰기, 인용, 목록
- **광고 걸러 내기**: 덤프에 함께 담긴 광고(파워링크 등)를 지우고 보여 줍니다.
- **처음 화면**: 이어서 읽기, 즐겨찾기, 둘러볼 만한 문서
- **화면 설정**: 시스템, 라이트, 다크 모드(다크에서는 나무위키의 다크 모드 색 사용), 글꼴(기본 Pretendard, 설치된 글꼴 선택 가능), 글자 크기, 본문 너비
- **보관함**: 최근 본 문서, 즐겨찾기. 방문 기록은 설정에서 끌 수 있습니다.
- **없는 문서 표시**: 덤프에 없는 문서로 가는 링크는 빨갛게 표시하고, 누르면 비슷한 제목을 제안합니다.
- **맥**: 트랙패드, 매직 마우스로 쓸어서 뒤로, 앞으로 가기, 문서 끝에서 튕기기, Liquid Glass 아이콘(macOS 26 이상)

## 지원 환경

| 운영체제 | 구조 | 내려받을 파일 |
|---|---|---|
| macOS 12 이상 | Apple Silicon | `namudump-<버전>-mac-arm64.dmg` |
| Windows 10, 11 | x64, Arm64 | `namudump-<버전>-win-x64-setup.exe`, `namudump-<버전>-win-arm64-setup.exe` |
| Linux | x64, arm64 | `namudump-<버전>-linux-x86_64.AppImage`, `namudump-<버전>-linux-arm64.AppImage`, `.deb` |

## 설치

[최신 릴리스](../../releases/latest)에서 내 컴퓨터에 맞는 파일을 내려받습니다.

### macOS

1. `.dmg`를 열고, 창에 보이는 **나무덤프**를 옆의 **응용 프로그램** 폴더로 끌어다 놓습니다.
2. 응용 프로그램 폴더에서 나무덤프를 엽니다.

**"확인되지 않은 개발자"라며 열리지 않을 때**: 애플의 인증을 받지 않은 앱이라서 그렇습니다. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 **그래도 열기**를 누르세요.

**"손상되었기 때문에 열 수 없습니다"라고 나올 때**: 터미널에서 다음을 한 번 실행한 뒤 다시 여세요. 앱은 파인더에 '나무덤프'로 보이지만 실제 파일 이름은 `NamuDump.app`입니다.

```bash
xattr -dr com.apple.quarantine /Applications/NamuDump.app
```

### Windows

설치 파일(`-setup.exe`)을 실행합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명하지 않은 프로그램이라 뜨는 경고입니다.

### Linux

AppImage는 실행 권한을 주고 바로 엽니다. Debian, Ubuntu 계열은 `.deb`로 설치해도 됩니다.

```bash
chmod +x namudump-*.AppImage
./namudump-*.AppImage
```

## 처음 실행

첫 화면에서 덤프 파일(.sqlite)을 고릅니다. 한 번 고른 뒤로는 그 파일을 기억합니다. 외장 드라이브에 둔 파일도 열 수 있습니다.

## 쓰는 법

macOS는 ⌘, Windows와 Linux는 Ctrl을 씁니다.

| 단축키 | 동작 |
|---|---|
| ⌘K 또는 / | 검색창으로 |
| ⌘[ , ⌘] (Alt+←, Alt+→) | 뒤로, 앞으로 |
| ⌘⇧H | 처음 화면 |
| ⌘F | 문서 안에서 찾기 |
| ⌘R | 아무 문서 |
| ⌘D | 즐겨찾기에 넣기, 빼기 |
| ⌘Y | 보관함(최근 본 문서, 즐겨찾기) |
| ⌘N | 새 창(macOS) |
| ⌘, | 설정 |
| ⌘+ , ⌘− , ⌘0 | 글자 크게, 작게, 원래대로 |
| esc | 찾기 막대, 말풍선, 설정 닫기 |

- 맥에서는 트랙패드 두 손가락 쓸기, 매직 마우스 한 손가락 쓸기로 뒤로, 앞으로 갈 수 있습니다. 돌아오면 읽던 자리가 그대로입니다.
- 문서에서 글자를 골라 오른쪽 클릭하면 그 말로 제목을 검색할 수 있습니다.
- 외부 링크는 기본 웹 브라우저로 열립니다. 유튜브 같은 동영상은 누르면 문서 안에서 재생합니다(인터넷 필요).

## 한계

- **이미지를 표시하지 않습니다**: 덤프에 이미지 파일이 없어서, 이미지 자리에는 원래 크기의 틀과 설명만 보여 줍니다.
- **제목만 검색합니다**: 본문 내용 검색은 지원하지 않습니다.
- **본문만 있습니다**: 역링크, 문서 역사, 토론은 볼 수 없습니다.
- **덤프 시점의 내용입니다**: 덤프 이후에 바뀐 내용은 반영되지 않습니다. 문서마다 "나무위키에서 보기" 단추로 최신판을 열 수 있습니다.

## 데이터와 개인정보

- 덤프 파일은 읽기만 하고 절대 고치지 않습니다.
- 설정, 즐겨찾기, 방문 기록은 이 컴퓨터에만 저장합니다. 어디로도 보내지 않습니다.
  - macOS: `~/Library/Application Support/NamuDump`
  - Windows: `%APPDATA%\NamuDump`
  - Linux: `~/.config/NamuDump`
- 인터넷은 유튜브 동영상의 썸네일을 보이거나, 동영상을 재생하거나, 외부 링크를 열 때만 씁니다. 썸네일은 동영상이 있는 부분을 볼 때만 유튜브(`i.ytimg.com`)에서 받고, 인터넷이 없으면 검은 바탕으로 둡니다. 그 밖의 외부 그림은 받지 않습니다.

## 업데이트와 삭제

- **업데이트**: 새 버전을 같은 방법으로 설치하면 됩니다. 설정과 기록은 그대로 남습니다.
- **삭제**: macOS는 응용 프로그램 폴더의 나무덤프를 휴지통에 넣고, Windows는 설정의 앱 목록에서 제거합니다. 설정과 기록까지 지우려면 위의 저장 폴더도 지웁니다.
